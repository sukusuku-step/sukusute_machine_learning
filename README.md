# PyTorchで機械学習を回す

## 環境構築

### 1. 仮想環境の作成（初回のみ）

```bash
python3 -m venv .venv
```

### 2. 仮想環境の有効化

```bash
source .venv/bin/activate
```

### 3. 必要なライブラリのインストール

```bash
pip install -r requirements.txt // 結構時間がかかる
```

---

## 学習

### 実行方法

```bash
mkdir models/saved // 学習済みモデルを保存するためのフォルダを作成
python -m training.train
```

### 内容

* ダミーデータを乱数値で生成
* PyTorch用のDatasetを作成
* 単純なMLPモデルを学習させる（深層学習）
* 学習済みモデルを `models/saved/mlp_prototype.pth` で保存

---

## 推論

### 実行方法

```bash
python -m inference.predict
```

### 内容

* 学習済みモデルを読み込み
* サンプルデータを1つ乱数値で生成して入力
* 学習済みモデルで健康状態を推論
* 推論結果を表示

---

## モデル評価

### 実行方法

```bash
python -m inference.evaluate
```

### 内容

* 学習済みモデルを読み込み
* ランダムなダミーデータを100件生成
* 100件すべてについて推論を実行
* 正解ラベルと推論結果を比較
* 最終的なAccuracy（正解率）を表示

---

## 使用している特徴量

| 特徴量                 | 説明                     |
| ------------------- | ---------------------- |
| 歩数 (`step`)         | 現在の歩数                  |
| 歩数変化率 (`step_rate`) | 一定時間あたりの歩数の変化率         |
| 過去平均との差 (`diff`)    | データベースに保存された過去の歩数平均との差 |
| Roll                | X軸周りの姿勢                |
| Pitch               | Y軸周りの姿勢                |
| Yaw                 | Z軸周りの姿勢                |
| Roll変化率 (`droll`)   | Rollの変化速度              |
| Pitch変化率 (`dpitch`) | Pitchの変化速度             |
| Yaw変化率 (`dyaw`)     | Yawの変化速度               |

---

プロトタイプとして、PyTorchを用いたMLP（全結合ニューラルネットワーク）を実装

入力された9次元の特徴量ベクトルから

* 元気
* いつもよりも元気がない
* 転倒の可能性

の3クラスに分類するモデルを構築している

---

実データが収集したらダミーデータ生成部分を実データの読み込み処理へ置き換える  
CSV・DBから実データを読み込めるようにする  
入力データの正規化を考える  
学習率・Epoch数などのハイパーパラメータの調整  
層の数・各層のユニット数・活性化関数の最適化  
時系列モデル（LSTMやTransformerなど）やCNNの導入など  

以下の特徴量を追加したら推論の精度は上がりそう  

* 1時間・1日・1週間の平均歩数
* 歩数の分散や標準偏差
* 長時間座位・立位・歩行の継続時間
* 姿勢変化の頻度
* 転倒に特徴的な加速度・角速度パターン
* センサの生データ（加速度・ジャイロ・地磁気）
* 数分～数時間分のセンサデータ
* 数日～数週間分の歩数履歴
